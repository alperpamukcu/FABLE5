# The star track — how far a bar climbs, and how fast

60 runs, horizon **120 days** (twenty weeks). The 200-run
report answers the same question over thirty days and is cut off by it.

**This is a floor.** The bot reads only the ID, never shops and never buys
a brand, so a played bar climbs faster and probably further. What the
table is trusted for is the SHAPE: the spacing between rungs, and where
the curve stops moving. A rung nobody reaches in twenty weeks is a rung
no guest can be written for until something else changes.
